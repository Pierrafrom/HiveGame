Detailed Description

Represents a hexagonal cell in the Hive game board using cube coordinates.

The Hex class models a hexagonal grid cell with cube coordinates (x, y, z), where x + y + z must always equal zero. This representation simplifies the computation of neighboring cells and distances within the grid.
