\doxysubsection{Detailed Description}
Represents the game board for the Hive game. 

The \doxylink{classhive_1_1models_1_1Board}{Board} class manages the hexagonal grid on which the Hive game is played. It handles the placement and removal of pieces, as well as the dynamic creation and deletion of hexes (cells) as the game progresses. The board ensures that there is always a single ring of empty hexes surrounding the cluster of pieces.

The board is represented as a map of hex locations to a stack of pieces. 

Each \doxylink{classhive_1_1models_1_1Hex}{Hex} key corresponds to a stack of {\ttfamily std\+::shared\+\_\+ptr\texorpdfstring{$<$}{<}\doxylink{classhive_1_1models_1_1Piece}{Piece}\texorpdfstring{$>$}{>}}, representing the pieces stacked at that hex location. The ownership of the \doxylink{classhive_1_1models_1_1Piece}{Piece} objects is shared between the \doxylink{classhive_1_1models_1_1Board}{Board} and the \doxylink{classhive_1_1models_1_1Player}{Player} class.
