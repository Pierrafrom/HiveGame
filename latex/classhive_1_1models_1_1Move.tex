\doxysubsection{Detailed Description}
Represents a move in the Hive game. 

The {\ttfamily \doxylink{classhive_1_1models_1_1Move}{Move}} class encapsulates the data required to execute and undo a move. A move can either be placing a new piece or moving an existing piece on the board. Objects of this class are immutable once created.
