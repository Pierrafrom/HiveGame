\doxysubsection{Detailed Description}
Factory class for creating game pieces in the Hive game. 

The {\ttfamily \doxylink{classhive_1_1models_1_1PieceFactory}{Piece\+Factory}} class provides a centralized mechanism for creating various types of pieces in the Hive game. It ensures consistent and flexible piece creation while encapsulating construction logic.
